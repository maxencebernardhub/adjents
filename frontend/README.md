# Adjents — Frontend

React 19 + TypeScript + PixiJS frontend for the Adjents agent platform.

See the [main README](../README.md) and [ARCHITECTURE.md](../docs/ARCHITECTURE.md) for full documentation.

## Development

```bash
pnpm install
pnpm dev
```

## Tests

```bash
pnpm test
```

## Lint & type-check

```bash
pnpm lint && pnpm format:check
pnpm typecheck
```
